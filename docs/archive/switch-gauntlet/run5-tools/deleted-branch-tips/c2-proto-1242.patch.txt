Subject: [PATCH 01/11] Boot-test filter and repeat; serialized fault dumps
 with CPU-tagged lines

Test filter: a boot-test kernel runs only the named RUN_TEST functions
(exact names, comma-separated), N passes, one [ITER k/N] line per run with
its result and elapsed time, then a per-test summary and the usual summary
block. Sources: slmos.test= / slmos.test_repeat= on the kernel command
line (ARM64 /chosen/bootargs), make kernel-test TEST_FILTER= TEST_REPEAT=
(build time, used on both Jetson paths), and the ktest shell command.
Suites are selected through a name -> suite index generated at build time
(scripts/gen-test-index.py). With no filter the output is unchanged.

Fault dumps: panic(), the ARM64 EL1 sync/page-fault dump, the SLOT_TRACE
bad-SP dump and the x86-64 exception dump take a dump lock. A waiter gives
up after the holder has printed nothing for 50 ms (generic timer counter)
or 5 s in all, then dumps anyway. Every line a dumping CPU prints carries
"[cpuN] ". The dumping CPU skips the UART lock and holds it when free.
Skipped pre-MMU (spinlock_hw_enabled 0). FAULT_DUMP_SELFTEST=ON forces two
concurrent faults on CPUs 1 and 2.

+### Running Selected Tests (Filter and Repeat)
+
+A boot-test kernel can run only some tests, many times. The filter is a
+comma-separated list of exact `RUN_TEST` names (letters, digits and `_`, at
+most 16 names of at most 95 characters); the repeat count is the number of
+passes over those names, 1 to 1000000 (default 1). Each pass enters the
+suites that hold the named tests in the usual suite order and runs each named
+test once, so `a,b` with repeat 3 runs `a b a b a b`. Tests that are not
+named are skipped without output; the Rust FFI tests are skipped.
+
+The filter comes from the first of these that is set:
+
+| Source | Syntax | Notes |
+|--------|--------|-------|
+| Kernel command line (`/chosen/bootargs`, ARM64) | `slmos.test=<a,b> slmos.test_repeat=<N>` | Pi 5 `cmdline.txt`. Tokens may sit anywhere in the line. QEMU boots the ELF with no device tree (`DTB parsing failed`), and x86-64 reads no command line: use the build-time filter there. |
+| Build time | `make kernel-test TEST_FILTER=<a,b> TEST_REPEAT=<N>` (also `make test ...`) | Baked into the image; used when the command line has no `slmos.test=`. The flags are part of the build signature, so a later build without them re-configures and drops the filter. |
+| Shell of a boot-test kernel | `ktest <a,b> [N]` | After the boot run has finished (hardware only; QEMU exits after the run). |
+
+A filtered run prints, in place of the per-suite `[TEST]` headers and
+counts:
+
+```
+[FILTER] tests=test_preempt_flag_follows_migrated_task repeat=50 source=cmdline index=2879
+  [ITER 1/50]  [PASS] test_preempt_flag_follows_migrated_task (41210 us)
+  ...
+  [ITER 50/50]  [PASS] test_preempt_flag_follows_migrated_task (40877 us)
+
+[FILTER] Summary
+[FILTER] [PASS] test_preempt_flag_follows_migrated_task: runs=50 passed=50 failed=0 ignored=0 us min=... avg=... max=...
+
+========================================
+Test Suite Summary
+========================================
+[PASS] All test suites passed!
+```
+
+One `[ITER k/N]` line is printed when each run of a test finishes, with its
+result and elapsed time (generic timer counter on ARM64, TSC on x86-64). A
+fault inside run k therefore shows `[ITER k-1/N]` as the last line before the
+dump. Assertion messages print as usual above the iteration line. A name
+that never ran (a typo, or a test compiled out on this platform) is a
+`[FAIL] ... not found (0 runs)` line and counts as a failure; an unparseable
+filter fails the run before any test (`[FILTER] [FAIL] ... unparseable`).
+With no filter, the output is unchanged.
+
+Suite selection uses an index from test name to suite, generated at build
+time from the `RUN_TEST` lists by `scripts/gen-test-index.py`
+(`build/kernel-test/generated/test_index_gen.c`). A name missing from the
+index makes the run enter every suite (slower, still correct) and says so.
+Suite code outside `RUN_TEST` (setup lines, `migrate_spin_cleanup()` at the
+end of the scheduler suite) runs once per pass in the selected suites.
+
+**How each hardware boot path passes it.** The Jetson boot paths cannot
+pass a command line without changing the board: `slmos-kexec` passes Linux's
+own `/proc/cmdline` (it has no option to append to it), and the UEFI-direct
+path boots `SLMOS.efi` with the firmware's device tree. Use the build-time
+filter on both, and on Pi 5 too unless the card's `cmdline.txt` is to be
+edited:
+
+```bash
+# Jetson kexec: build, then deploy and boot as usual (slmos-kexec <elf>).
+make kernel-test PLATFORM=JETSON_ORIN_NANO \
+    TEST_FILTER=test_preempt_flag_follows_migrated_task TEST_REPEAT=200
+#   -> build/kernel-test/slmos.elf
+
+# Jetson UEFI-direct: the same build (plus any flags the image needs, such
+# as the operator library); deploy build/kernel-test/slmos.bin with
+# scripts/jetson-uefi-deploy.sh and boot with BootNext as usual.
+make kernel-test PLATFORM=JETSON_ORIN_NANO \
+    TEST_FILTER=test_checkerboard_fragmentation,test_exhaustion_recovery TEST_REPEAT=100
+
+# Pi 5: the same build-time flags (deploy the test image as kernel_2712.img
+# and kernel8.img), or leave the image unfiltered and append to the single
+# line of cmdline.txt on the boot partition:
+#   slmos.test=test_preempt_flag_follows_migrated_task slmos.test_repeat=200
+make kernel-test PLATFORM=RASPI5 \
+    TEST_FILTER=test_preempt_flag_follows_migrated_task TEST_REPEAT=200
+```
+
+The banner line `[FILTER] tests=... repeat=... source=build|cmdline|shell`
+records which filter the kernel ran. In QEMU:
+
+```bash
+make test TEST_FILTER=test_preempt_flag_follows_migrated_task TEST_REPEAT=50
+make test TEST_TIMEOUT=600 TEST_FILTER=... TEST_REPEAT=...   # long runs
+```
+
+**Deviation from a boot argument (switch gauntlet run 5).** Run 5's brief
+asked for a filter passed as a kernel command line or boot argument on all
+three hardware paths. The command-line source exists and is used on Pi 5,
+but neither Jetson path can carry it without changing the board (the

+forbid, so both Jetson paths use the build-time filter instead. The
+command-line parser is covered by `kernel/tests/test_test_filter.c`; it has
+not been exercised on hardware by run 5's C1.
+
+### Fault Dumps
+
+Exception and panic dumps are serialized (`kernel/include/fault_dump.h`,
+`kernel/src/fault_dump.c`). Each dump path calls `fault_dump_begin()` with
+IRQs masked and `fault_dump_end()` after its last line, right before the
+CPU halts: `panic()`, the ARM64 EL1 synchronous handler (page-fault dump,
+SLOT_TRACE fault lines), the SLOT_TRACE bad-SP dump, and the x86-64
+exception dump.
+
+- **One dump at a time.** A CPU that faults while another dumps waits for
+  the dump lock until the holder finishes, or until the holder has printed
+  nothing for 50 ms, measured on the generic timer counter (TSC on x86-64),
+  or 5 s in all. Then it dumps anyway and its first line says why
+  (`fault_dump: cpu1 holds the dump lock and printed nothing for 50 ms;
+  dumping without it`). A holder that faulted or hung mid-dump therefore
+  delays another dump by about 50 ms and never blocks it. A healthy dump
+  prints a line every few milliseconds, so a second dump waits for it to
+  finish instead of interleaving.
+- **Every line carries its CPU.** While a CPU dumps, every line it prints
+  through `uart_puts`/`uart_printf` (locked or not) starts with `[cpuN] `,
+  including lines printed by helpers such as the stack-canary check and the
+  SLOT_TRACE dump.
+- **No lock can block a dump.** The dumping CPU's own prints skip the UART
+  lock. The dump takes the UART lock itself if it is free within 20 ms, so
+  other CPUs' ordinary prints wait instead of splitting dump lines; if it is
+  not (a CPU faulted while printing), the dump prints without it.
+- **Early boot.** Before `vmm_init` sets `spinlock_hw_enabled` (MMU off, only
+  the boot CPU running) the dump lock is skipped, because exclusive accesses
+  to non-cacheable memory abort on Cortex-A78AE; the dump prints
+  `fault_dump: no dump lock (MMU off or no timer)` and still prefixes lines.
+  A counter that stops moving cannot turn the wait into a hang: after 10^6
+  polls with no change the wait ends.
+- **x86-64.** The exception handler in `kernel/arch/x86_64/idt.c` and
+  `panic()` use the same lock and prefixes. x86-64 runs the boot-test suite
+  on one CPU, so the lock is never contended there.
+
+`kernel/tests/test_fault_dump.c` tests the lock on private instances (free,
+nested, silent holder times out at the stall bound, printing holder holds
+until the cap, release hand-off, frozen counter). `make test
+FAULT_DUMP_SELFTEST=ON` (ARM64, default OFF, no code when OFF) builds a test
+kernel that faults CPU 1 (data abort) and CPU 2 (BRK) at the same instant
+and checks that both dumps complete; the harness runs only that test,
+because CPUs 1 and 2 stay halted, and the log shows the two dumps one after
+the other.
+

+/*
+ * fault_dump.h - Serialized exception and panic dumps.
+ *
+ * A dump (panic(), the EL1 page-fault dump, the x86-64 exception dump,
+ * the SLOT_TRACE bad-SP dump) runs between fault_dump_begin() and
+ * fault_dump_end(). Inside that window:
+ *
+ *   - At most one CPU holds the dump lock. A second CPU that faults waits
+ *     until the holder ends its dump, or until the holder has printed
+ *     nothing for FAULT_DUMP_STALL_MS (default 50 ms, measured with the
+ *     generic timer / TSC counter, not a loop count), or until
+ *     FAULT_DUMP_CAP_MS in all; then it dumps anyway. A holder that
+ *     faulted or hung mid-dump therefore delays another CPU's dump by
+ *     about 50 ms at most and never blocks it.
+ *   - Every line the dumping CPU prints starts with "[cpuN] ", so even a
+ *     dump printed without the lock stays attributable line by line.
+ *   - The dumping CPU's uart_puts()/uart_printf() skip the UART lock (a
+ *     faulted holder of that lock cannot block the dump), and the dump
+ *     holds the UART lock itself when it can get it within
+ *     FAULT_DUMP_UART_WAIT_MS, so other CPUs' ordinary prints do not
+ *     split dump lines.
+ *
+ * Callers run with IRQs masked. Before vmm_init sets spinlock_hw_enabled
+ * (pre-MMU, only the boot CPU runs) the lock is skipped: exclusive
+ * accesses to non-cacheable memory abort on Cortex-A78AE. With no timer
+ * frequency yet, the wait is skipped too. Both cases still prefix lines.
+ * See docs/testing.md "Fault dumps".
+ */
+
+#ifndef FAULT_DUMP_H
+#define FAULT_DUMP_H
+
+#include <stdbool.h>
+#include <stdint.h>
+
+#define FAULT_DUMP_STALL_MS      50u
+#define FAULT_DUMP_CAP_MS        5000u
+#define FAULT_DUMP_UART_WAIT_MS  20u
+
+/* How this CPU entered the dump (fault_dump_begin's result). */
+typedef enum {
+    FAULT_DUMP_ACQUIRED = 0,    /* took the dump lock */
+    FAULT_DUMP_NESTED   = 1,    /* already held it (fault inside a dump) */
+    FAULT_DUMP_STALLED  = 2,    /* holder silent FAULT_DUMP_STALL_MS: dumped anyway */
+    FAULT_DUMP_CAPPED   = 3,    /* waited FAULT_DUMP_CAP_MS in all: dumped anyway */
+    FAULT_DUMP_NOLOCK   = 4,    /* pre-MMU or no timer: no lock taken */
+} fault_dump_entry_t;
+
+/* The lock. One instance serves every dump; tests use their own. */
+struct fault_dump_lock {
+    volatile uint32_t owner;        /* 0 = free, else CPU id + 1 */
+    volatile uint64_t progress;     /* holder's counter value at its last line */
+};
+
+/* Start a dump on this CPU (IRQs already masked). Idempotent per CPU. */
+fault_dump_entry_t fault_dump_begin(void);
+
+/* End this CPU's dump: release the lock and UART lock if held, stop
+ * prefixing. Call after the last line, right before halting. */
+void fault_dump_end(void);
+
+/* Number of dumps that reached fault_dump_end() since boot. */
+uint32_t fault_dump_completed(void);
+
+/* Lock primitive, exposed for tests. `me` is the caller's CPU id.
+ * stall_ticks / cap_ticks are counter ticks; now() reads the counter. */
+fault_dump_entry_t fault_dump_lock_acquire(struct fault_dump_lock *l,

+                                           uint64_t stall_ticks,

+ *
+ * See fault_dump.h for the contract. Run 4b of the switch gauntlet lost
+ * two Jetson boots to dumps from two CPUs interleaved character by

+static struct fault_dump_lock dump_lock;
+static volatile uint32_t dumps_completed;

+/* Per-CPU dump state, touched only by its own CPU. */

+/* A counter that stops moving (x86-64's PIT fallback with IRQs off)
+ * would make a tick-bounded wait unbounded: after this many polls with
+ * no change, give up as if the cap had expired. */
+#define FAULT_DUMP_FROZEN_POLLS 1000000u
+
+static inline void dump_cpu_relax(void)
+{
+#if defined(PLATFORM_X86_64)
+    __asm__ volatile("pause" ::: "memory");
+#else
+    __asm__ volatile("yield" ::: "memory");
+#endif
+}

+static uint32_t dump_cpu(void)
+{
+    uint32_t me = cpu_id();
+    return me < MAX_CPUS ? me : 0;
+}
+
+fault_dump_entry_t fault_dump_lock_acquire(struct fault_dump_lock *l,
+                                           uint32_t me,
+                                           uint64_t stall_ticks,
+                                           uint64_t cap_ticks,
+                                           uint64_t (*now)(void))
+{
+    const uint32_t want = me + 1u;
+    if (__atomic_load_n(&l->owner, __ATOMIC_ACQUIRE) == want) {
+        return FAULT_DUMP_NESTED;
+    }
+
+    const uint64_t start = now();
+    uint32_t seen_owner = __atomic_load_n(&l->owner, __ATOMIC_RELAXED);
+    uint64_t seen_progress = l->progress;
+    uint64_t seen_at = start;
+    uint64_t last_now = start;
+    uint32_t frozen = 0;
+
+    for (;;) {
+        uint32_t expected = 0;
+        if (__atomic_compare_exchange_n(&l->owner, &expected, want, false,
+                                        __ATOMIC_ACQUIRE, __ATOMIC_RELAXED)) {
+            l->progress = now();
+            return FAULT_DUMP_ACQUIRED;
+        }
+
+        const uint64_t t = now();
+        const uint64_t p = l->progress;
+        /* Any sign of life restarts the silence timer: a new owner, or the
+         * owner printing another line. */
+        if (expected != seen_owner || p != seen_progress) {
+            seen_owner = expected;
+            seen_progress = p;
+            seen_at = t;
+        }
+        if (t - seen_at >= stall_ticks) {
+            return FAULT_DUMP_STALLED;
+        }
+        if (t - start >= cap_ticks) {
+            return FAULT_DUMP_CAPPED;
+        }
+        if (t == last_now) {
+            if (++frozen >= FAULT_DUMP_FROZEN_POLLS) {
+                return FAULT_DUMP_CAPPED;
+            }
+        } else {
+            frozen = 0;
+            last_now = t;
+        }
+        dump_cpu_relax();
+    }
+}

+void fault_dump_lock_release(struct fault_dump_lock *l, uint32_t me)
+{
+    uint32_t want = me + 1u;
+    (void)__atomic_compare_exchange_n(&l->owner, &want, 0u, false,
+                                      __ATOMIC_RELEASE, __ATOMIC_RELAXED);
+}

+static uint64_t dump_now(void)
+{
+    return timer_get_count();
+}
+
+fault_dump_entry_t fault_dump_begin(void)
+{
+    const uint32_t me = dump_cpu();
+    const uint32_t bit = 1u << me;
+
+    if (fault_dump_cpus & bit) {
+        return FAULT_DUMP_NESTED;
+    }
+
+    const bool hw = spinlock_hw_enabled != 0;
+    const uint64_t freq = timer_get_frequency();
+    fault_dump_entry_t entry;
+    uint32_t holder = 0;
+
+    if (!hw || freq == 0) {
+        entry = FAULT_DUMP_NOLOCK;
+    } else {
+        holder = __atomic_load_n(&dump_lock.owner, __ATOMIC_RELAXED);
+        entry = fault_dump_lock_acquire(&dump_lock, me,
+                                        freq * FAULT_DUMP_STALL_MS / 1000u,
+                                        freq * FAULT_DUMP_CAP_MS / 1000u,
+                                        dump_now);
+        if (entry != FAULT_DUMP_ACQUIRED) {
+            uint32_t h = __atomic_load_n(&dump_lock.owner, __ATOMIC_RELAXED);
+            if (h != 0) {
+                holder = h;
+            }
+        }
+    }
+
+    dump_entry[me] = entry;
+    dump_line_start[me] = true;
+    dump_uart_held[me] = false;
+    if (hw) {
+        __atomic_fetch_or(&fault_dump_cpus, bit, __ATOMIC_ACQ_REL);
+    } else {
+        fault_dump_cpus |= bit;     /* pre-MMU: only the boot CPU runs */
+    }
+
+    /* Hold the UART lock so other CPUs' ordinary prints wait until the
+     * dump ends. A CPU that faulted while holding it (or a faulted
+     * holder elsewhere) costs FAULT_DUMP_UART_WAIT_MS, then the dump
+     * prints without it. */
+    if (entry == FAULT_DUMP_ACQUIRED) {
+        dump_uart_held[me] = uart_lock_try_hold(
+            freq * FAULT_DUMP_UART_WAIT_MS / 1000u, dump_now);
+    }
+
+    switch (entry) {
+    case FAULT_DUMP_STALLED:
+        uart_printf_unlocked("fault_dump: cpu%u holds the dump lock and printed "
+                             "nothing for %u ms; dumping without it\n",
+                             holder ? holder - 1u : 0u, FAULT_DUMP_STALL_MS);
+        break;
+    case FAULT_DUMP_CAPPED:
+        uart_printf_unlocked("fault_dump: waited %u ms for the dump lock "
+                             "(holder cpu%u); dumping without it\n",
+                             FAULT_DUMP_CAP_MS, holder ? holder - 1u : 0u);
+        break;
+    case FAULT_DUMP_NOLOCK:
+        uart_puts_unlocked("fault_dump: no dump lock (MMU off or no timer)\n");
+        break;
+    default:
+        break;
+    }
+    return entry;
+}
+
+void fault_dump_end(void)
+{
+    const uint32_t me = dump_cpu();
+    const uint32_t bit = 1u << me;
+
+    if (!(fault_dump_cpus & bit)) {
+        return;
+    }
+    /* End the last line before the prefix stops. */
+    if (!dump_line_start[me]) {
+        uart_puts_unlocked("\n");
+    }
+    if (dump_uart_held[me]) {
+        dump_uart_held[me] = false;
+        uart_lock_hold_release();
+    }
+
+    const bool hw = spinlock_hw_enabled != 0;
+    if (dump_entry[me] == FAULT_DUMP_ACQUIRED) {
+        fault_dump_lock_release(&dump_lock, me);
+    }
+    if (hw) {
+        __atomic_fetch_and(&fault_dump_cpus, ~bit, __ATOMIC_ACQ_REL);
+        __atomic_fetch_add(&dumps_completed, 1u, __ATOMIC_RELEASE);
+    } else {
+        fault_dump_cpus &= ~bit;
+        dumps_completed++;
+    }
+}
+
+uint32_t fault_dump_completed(void)
+{
+    return __atomic_load_n(&dumps_completed, __ATOMIC_ACQUIRE);
+}

+bool fault_dump_this_cpu(void)
+{
+    uint32_t mask = fault_dump_cpus;
+    return mask != 0 && (mask & (1u << dump_cpu())) != 0;
+}

+{

+static bool is_name_char(char c)
+{
+    return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') ||
+           (c >= '0' && c <= '9') || c == '_';
+}
+
+static bool is_space(char c)
+{
+    return c == ' ' || c == '\t' || c == '\n' || c == '\r';
+}
+
+int test_filter_parse_names(test_filter_t *f, const char *csv, size_t len)
+{
+    if (f == NULL || csv == NULL || len == 0) {
+        return TEST_FILTER_ERR_EMPTY;
+    }
+
+    uint32_t count = 0;
+    size_t i = 0;
+    while (i <= len) {
+        size_t start = i;
+        while (i < len && csv[i] != ',') {
+            if (!is_name_char(csv[i])) {
+                return TEST_FILTER_ERR_CHAR;
+            }
+            i++;
+        }
+        size_t n = i - start;
+        if (n == 0) {
+            return TEST_FILTER_ERR_EMPTY;       /* "a,,b", ",a" or "a," */
+        }
+        if (n >= TEST_FILTER_NAME_MAX) {
+            return TEST_FILTER_ERR_TOO_LONG;
+        }
+        if (count >= TEST_FILTER_MAX_NAMES) {
+            return TEST_FILTER_ERR_TOO_MANY;
+        }
+        for (size_t k = 0; k < n; k++) {
+            f->names[count][k] = csv[start + k];
+        }
+        f->names[count][n] = '\0';
+        count++;
+        i++;                                    /* skip the comma (or end) */
+    }
+    f->count = count;
+    return TEST_FILTER_OK;
+}
+
+int test_filter_parse_repeat(const char *s, size_t len, uint32_t *out)
+{
+    if (s == NULL || out == NULL || len == 0 || len > 7) {
+        return TEST_FILTER_ERR_REPEAT;
+    }
+    uint32_t v = 0;
+    for (size_t i = 0; i < len; i++) {
+        if (s[i] < '0' || s[i] > '9') {
+            return TEST_FILTER_ERR_REPEAT;
+        }
+        v = v * 10u + (uint32_t)(s[i] - '0');
+    }
+    if (v == 0 || v > TEST_FILTER_REPEAT_MAX) {
+        return TEST_FILTER_ERR_REPEAT;
+    }
+    *out = v;
+    return TEST_FILTER_OK;
+}
+
+const char *test_filter_find_kv(const char *cmdline, const char *key,
+                                size_t *out_len)
+{
+    if (cmdline == NULL || key == NULL || out_len == NULL) {
+        return NULL;
+    }
+    size_t klen = 0;
+    while (key[klen] != '\0') {
+        klen++;
+    }
+
+    const char *p = cmdline;
+    while (*p != '\0') {
+        while (is_space(*p)) {
+            p++;
+        }
+        if (*p == '\0') {
+            break;
+        }
+        const char *tok = p;
+        while (*p != '\0' && !is_space(*p)) {
+            p++;
+        }
+        size_t tlen = (size_t)(p - tok);
+        if (tlen > klen && tok[klen] == '=') {
+            bool eq = true;
+            for (size_t i = 0; i < klen; i++) {
+                if (tok[i] != key[i]) {
+                    eq = false;
+                    break;
+                }
+            }
+            if (eq) {
+                *out_len = tlen - klen - 1;
+                return tok + klen + 1;
+            }
+        }
+    }
+    return NULL;
+}
+
+int test_filter_from_cmdline(test_filter_t *f, const char *cmdline)
+{
+    size_t nlen = 0;
+    const char *names = test_filter_find_kv(cmdline, TEST_FILTER_KEY_NAMES,
+                                            &nlen);
+    if (names == NULL) {
+        return 0;
+    }
+
+    test_filter_t tmp = { 0 };
+    int rc = test_filter_parse_names(&tmp, names, nlen);
+    if (rc != TEST_FILTER_OK) {
+        return rc;
+    }
+
+    tmp.repeat = 1;
+    size_t rlen = 0;
+    const char *rep = test_filter_find_kv(cmdline, TEST_FILTER_KEY_REPEAT,
+                                          &rlen);
+    if (rep != NULL) {
+        rc = test_filter_parse_repeat(rep, rlen, &tmp.repeat);
+        if (rc != TEST_FILTER_OK) {
+            return rc;
+        }
+    }
+
+    tmp.active = true;
+    tmp.source = "cmdline";
+    *f = tmp;
+    return 1;
+}
+
+int test_filter_index_of(const test_filter_t *f, const char *name)
+{
+    if (f == NULL || name == NULL) {
+        return -1;
+    }
+    for (uint32_t i = 0; i < f->count; i++) {
+        const char *a = f->names[i];
+        const char *b = name;
+        while (*a != '\0' && *a == *b) {
+            a++;
+            b++;
+        }
+        if (*a == '\0' && *b == '\0') {
+            return (int)i;
+        }
+    }
+    return -1;
+}

+                                                        uint32_t *cursor)
+{
+    (void)test_name;
+    (void)cursor;
+    return NULL;
+}
+
+__attribute__((weak)) uint32_t test_index_size(void)
+{
+    return 0;

+    size_t n = 0;

+static void harness_print_filter_error(const char *where, int rc)
+{
+    uart_printf("[FILTER] [FAIL] %s: unparseable test filter (error %d); "
+                "running nothing\n", where, rc);
+}

+/* Set g_test_filter from (in order) the kernel command line and the
+ * build-time default. Returns 1 when a filter is active, 0 when none
+ * was given, or a negative error (the caller fails the run). */
+static int harness_filter_from_boot(void)
+{
+#if !defined(PLATFORM_X86_64)
+    const dtb_chosen_t *chosen = dtb_get_chosen();
+    if (chosen != NULL && chosen->bootargs[0] != '\0') {
+        int rc = test_filter_from_cmdline(&g_test_filter, chosen->bootargs);
+        if (rc < 0) {
+            harness_print_filter_error("kernel command line", rc);
+            return rc;
+        }
+        if (rc == 1) {
+            return 1;
+        }
+    }
+#endif
+    size_t nlen = cstrlen(harness_build_filter);
+    if (nlen == 0) {
+        return 0;
+    }
+    test_filter_t f = { 0 };
+    int rc = test_filter_parse_names(&f, harness_build_filter, nlen);
+    if (rc == TEST_FILTER_OK) {
+        f.repeat = 1;
+        size_t rlen = cstrlen(harness_build_repeat);
+        if (rlen != 0) {
+            rc = test_filter_parse_repeat(harness_build_repeat, rlen, &f.repeat);
+        }
+    }
+    if (rc != TEST_FILTER_OK) {
+        harness_print_filter_error("build-time TEST_FILTER/TEST_REPEAT", rc);
+        return rc;
+    }
+    f.active = true;
+    f.source = "build";
+    g_test_filter = f;
+    return 1;
+}

+/* Run the active filter: g_test_filter.repeat passes over the named
+ * tests, each pass entering the selected suites in the usual order, so
+ * "a,b" with repeat 3 runs a b a b a b. Returns the failure count:
+ * failed iterations plus one for each name that never ran. */
+static int harness_run_filtered(void)
+{
+    test_filter_t *f = &g_test_filter;
+    int total_failures = 0;
+
+    for (uint32_t i = 0; i < TEST_FILTER_MAX_NAMES; i++) {
+        g_test_filter_stats[i] = (test_filter_stats_t){ 0 };
+    }
+
+    harness_walk_all = false;
+    uart_puts("[FILTER] tests=");
+    for (uint32_t i = 0; i < f->count; i++) {
+        uart_printf("%s%s", i ? "," : "", f->names[i]);
+    }
+    uart_printf(" repeat=%u source=%s index=%u\n", f->repeat,
+                f->source ? f->source : "?", test_index_size());
+    for (uint32_t i = 0; i < f->count; i++) {
+        uint32_t cursor = 0;
+        if (test_index_next_suite(f->names[i], &cursor) == NULL) {
+            uart_printf("[FILTER] %s is not in the test index; entering every suite\n",
+                        f->names[i]);
+            harness_walk_all = true;
+        }
+    }
+
+    for (uint32_t pass = 1; pass <= f->repeat; pass++) {
+        g_test_filter_pass = pass;
+        total_failures += harness_run_suites();
+    }
+
+    uint64_t freq = timer_get_frequency();
+    uart_puts("\n[FILTER] Summary\n");
+    for (uint32_t i = 0; i < f->count; i++) {
+        const test_filter_stats_t *st = &g_test_filter_stats[i];
+        if (st->runs == 0) {
+            uart_printf("[FILTER] [FAIL] %s: not found (0 runs)\n", f->names[i]);
+            total_failures++;
+            continue;
+        }
+        uint64_t avg = st->total_ticks / st->runs;
+        uart_printf("[FILTER] %s %s: runs=%u passed=%u failed=%u ignored=%u "
+                    "us min=%lu avg=%lu max=%lu\n",
+                    st->failed ? "[FAIL]" : "[PASS]", f->names[i],
+                    st->runs, st->passed, st->failed, st->ignored,
+                    (unsigned long)(freq ? st->min_ticks * 1000000u / freq : 0),
+                    (unsigned long)(freq ? avg * 1000000u / freq : 0),
+                    (unsigned long)(freq ? st->max_ticks * 1000000u / freq : 0));
+    }
+    return total_failures;
+}

+int test_harness_run_all(void)
+{
+    int rc = harness_filter_from_boot();
+#if defined(FAULT_DUMP_SELFTEST) && !defined(PLATFORM_X86_64)
+    /* FAULT_DUMP_SELFTEST=ON: the forced double fault leaves CPUs 1 and 2
+     * halted, so run that test alone unless a filter was given. */
+    if (rc == 0) {
+        static const char selftest[] = "test_fault_dump_two_cpus_concurrent";
+        test_filter_t f = { 0 };
+        (void)test_filter_parse_names(&f, selftest, sizeof(selftest) - 1);
+        f.repeat = 1;
+        f.active = true;
+        f.source = "FAULT_DUMP_SELFTEST";
+        g_test_filter = f;
+        rc = 1;
+    }
+#endif
+    if (rc < 0) {
+        return test_harness_finish(1);
+    }
+    if (rc == 1) {
+        return test_harness_finish(harness_run_filtered());
+    }
+    return test_harness_finish(harness_run_suites());
+}

+/* `ktest <name[,name...]> [repeat]`: the same filtered run from the
+ * shell of a boot-test kernel, after the boot run has finished. */
+static int cmd_ktest(int argc, char *argv[])
+{
+    if (argc < 2 || argc > 3) {
+        uart_puts("usage: ktest <test[,test...]> [repeat]\n");
+        return 1;
+    }
+    test_filter_t f = { 0 };
+    int rc = test_filter_parse_names(&f, argv[1], cstrlen(argv[1]));
+    f.repeat = 1;
+    if (rc == TEST_FILTER_OK && argc == 3) {
+        rc = test_filter_parse_repeat(argv[2], cstrlen(argv[2]), &f.repeat);
+    }
+    if (rc != TEST_FILTER_OK) {
+        harness_print_filter_error("ktest", rc);
+        return 1;
+    }
+    f.active = true;
+    f.source = "shell";
+    g_test_filter = f;
+    int failures = harness_run_filtered();
+    g_test_filter.active = false;
+    uart_puts("\n[FILTER] ");
+    if (failures == 0) {
+        uart_puts("[PASS] ktest\n");
+    } else {
+        uart_printf("[FAIL] ktest: %d failure(s)\n", failures);
+    }
+    return failures == 0 ? 0 : 1;
+}

+#!/usr/bin/env python3
+"""Generate the boot-test name -> suite index used by the test filter.
+
+Usage: gen-test-index.py <output.c> <test source.c>...
+
+For every top-level function `int test_suite_X(void)` (or a helper
+function that a suite calls), collect the names passed to RUN_TEST() and
+RUN_*_TEST() macros in its body. Tests found in a helper are attributed to
+every suite that calls the helper (transitively). The harness uses the
+index to enter only the suites that hold the filtered tests; a name not in
+the index makes the harness walk every suite instead (slower, still
+correct), so a parse miss here costs time, not correctness.
+
+The output defines test_index_next_suite() and test_index_size(), which
+override the weak empty versions in kernel/tests/test_filter.c.
+"""
+
+import re
+import sys
+
+FUNC_RE = re.compile(r'^(?:static\s+)?(?:int|void)\s+(\w+)\s*\(\s*void\s*\)\s*$')
+FUNC_INLINE_RE = re.compile(r'^(?:static\s+)?(?:int|void)\s+(\w+)\s*\(\s*void\s*\)\s*\{\s*$')
+RUN_RE = re.compile(r'\bRUN_\w*TEST\s*\(\s*(\w+)\s*\)')
+CALL_RE = re.compile(r'\b(\w+)\s*\(')
+DEFINE_RE = re.compile(r'^\s*#\s*define\b')
+
+
+def strip_comments(text):
+    text = re.sub(r'/\*.*?\*/', lambda m: '\n' * m.group(0).count('\n'), text,
+                  flags=re.S)
+    return re.sub(r'//[^\n]*', '', text)
+
+
+def parse_functions(path):
+    """Return {func: (tests[], calls set)} for top-level functions."""
+    with open(path, encoding='utf-8', errors='replace') as fh:
+        lines = strip_comments(fh.read()).split('\n')
+    funcs = {}
+    i = 0
+    while i < len(lines):
+        line = lines[i]
+        m = FUNC_INLINE_RE.match(line)
+        start = None
+        if m:
+            start = i + 1
+        else:
+            m = FUNC_RE.match(line)
+            if m and i + 1 < len(lines) and lines[i + 1].strip() == '{':
+                start = i + 2
+        if start is None:
+            i += 1
+            continue
+        name = m.group(1)
+        tests = []
+        calls = set()
+        j = start
+        while j < len(lines) and not lines[j].startswith('}'):
+            body = lines[j]
+            if not DEFINE_RE.match(body):
+                tests.extend(RUN_RE.findall(body))
+                calls.update(CALL_RE.findall(body))
+            j += 1
+        funcs.setdefault(name, ([], set()))
+        funcs[name][0].extend(tests)
+        funcs[name][1].update(calls)
+        i = j + 1
+    return funcs
+
+
+def main():
+    if len(sys.argv) < 3:
+        sys.stderr.write(__doc__)
+        return 2
+    out = sys.argv[1]
+    funcs = {}
+    for path in sys.argv[2:]:
+        for name, (tests, calls) in parse_functions(path).items():
+            entry = funcs.setdefault(name, ([], set()))
+            entry[0].extend(tests)
+            entry[1].update(calls)
+
+    suites = sorted(n for n in funcs if n.startswith('test_suite_'))
+
+    # Tests reachable from each suite: its own RUN_TESTs plus those of any
+    # helper it calls, transitively.
+    pairs = []
+    for suite in suites:
+        seen = set()
+        stack = [suite]
+        names = []
+        while stack:
+            fn = stack.pop()
+            if fn in seen or fn not in funcs:
+                continue
+            seen.add(fn)
+            tests, calls = funcs[fn]
+            names.extend(tests)
+            for c in calls:
+                if c != fn and c in funcs and not c.startswith('test_suite_'):
+                    stack.append(c)
+        for t in dict.fromkeys(names):
+            pairs.append((t, suite))
+
+    pairs.sort()
+    with open(out, 'w', encoding='utf-8') as fh:
+        fh.write('/* Generated by scripts/gen-test-index.py. Do not edit. */\n')
+        fh.write('#include <stdint.h>\n#include <stddef.h>\n\n')
+        fh.write('struct test_index_entry { const char *test; const char *suite; };\n\n')
+        fh.write('static const struct test_index_entry test_index[] = {\n')
+        for t, s in pairs:
+            fh.write(f'    {{ "{t}", "{s}" }},\n')
+        fh.write('};\n\n')
+        fh.write('#define TEST_INDEX_COUNT (sizeof(test_index) / sizeof(test_index[0]))\n\n')
+        fh.write('static int index_streq(const char *a, const char *b)\n{\n'
+                 '    while (*a != 0 && *a == *b) { a++; b++; }\n'
+                 '    return *a == *b;\n}\n\n')
+        fh.write('const char *test_index_next_suite(const char *test_name, uint32_t *cursor);\n')
+        fh.write('uint32_t test_index_size(void);\n\n')
+        fh.write('const char *test_index_next_suite(const char *test_name, uint32_t *cursor)\n{\n'
+                 '    if (test_name == NULL || cursor == NULL) {\n        return NULL;\n    }\n'
+                 '    for (uint32_t i = *cursor; i < TEST_INDEX_COUNT; i++) {\n'
+                 '        if (index_streq(test_index[i].test, test_name)) {\n'
+                 '            *cursor = i + 1;\n'
+                 '            return test_index[i].suite;\n'
+                 '        }\n'
+                 '    }\n'
+                 '    *cursor = (uint32_t)TEST_INDEX_COUNT;\n'
+                 '    return NULL;\n}\n\n')
+        fh.write('uint32_t test_index_size(void)\n{\n'
+                 '    return (uint32_t)TEST_INDEX_COUNT;\n}\n')
+    return 0

+static uint32_t sc_restored[MAX_TASKS];  /* written by the switch-in CPU */
+static uint32_t sc_saved[MAX_TASKS];     /* written by the switch-out CPU */
+static uint32_t sc_owner[MAX_TASKS];     /* cpu + 1 while a CPU owns it */
+static struct switch_check_stats sc_stats;
+
+static int sc_index(struct task *t)
+{
+    struct task *base = task_slot(0);
+    if (!t || !base || t < base || t >= base + MAX_TASKS) {
+        return -1;                       /* not a task_table task */
+    }
+    return (int)(t - base);
+}
+
+/* Under the incoming CPU's rq_lock, before switch_to restores next. */
+void switch_check_in(struct task *next, uint32_t cpu)
+{
+    int i = sc_index(next);
+    if (i < 0) {
+        return;
+    }
+    uint32_t g = __atomic_load_n(&sc_restored[i], __ATOMIC_RELAXED);
+    uint32_t s = __atomic_load_n(&sc_saved[i], __ATOMIC_ACQUIRE);
+    uint32_t expect = 0;
+    int dual = !__atomic_compare_exchange_n(&sc_owner[i], &expect, cpu + 1, false,
+                                            __ATOMIC_ACQ_REL, __ATOMIC_ACQUIRE);
+    int bad = (s != g);
+    __atomic_fetch_add(&sc_stats.switch_ins, 1, __ATOMIC_RELAXED);
+    if (bad || dual) {
+        if (bad) {
+            __atomic_fetch_add(&sc_stats.bad_gen, 1, __ATOMIC_RELAXED);
+        }
+        if (dual) {
+            __atomic_fetch_add(&sc_stats.bad_dual, 1, __ATOMIC_RELAXED);
+        }
+        uint32_t zero = 0;
+        uint32_t kind = (uint32_t)(bad ? 1 : 0) | (uint32_t)(dual ? 2 : 0);
+        if (__atomic_compare_exchange_n(&sc_stats.first_kind, &zero, kind, false,
+                                        __ATOMIC_RELAXED, __ATOMIC_RELAXED)) {
+            sc_stats.first_task_id = next->id;
+            sc_stats.first_cpu = cpu;
+            sc_stats.first_owner = expect;
+        }
+        if (dual) {
+            /* Take ownership anyway so the next switch-out releases it. */
+            __atomic_store_n(&sc_owner[i], cpu + 1, __ATOMIC_RELEASE);
+        }
+    }
+    __atomic_store_n(&sc_restored[i], g + 1, __ATOMIC_RELAXED);
+}
+
+/* On the CPU that ran prev, after switch_to saved it, before on_cpu = 0. */
+void switch_check_out(struct task *prev)
+{
+    int i = sc_index(prev);
+    if (i < 0) {
+        return;
+    }
+    __atomic_store_n(&sc_owner[i], 0, __ATOMIC_RELAXED);
+    __atomic_store_n(&sc_saved[i], __atomic_load_n(&sc_restored[i], __ATOMIC_RELAXED),
+                     __ATOMIC_RELEASE);
+}
+
+void switch_check_snapshot(struct switch_check_stats *out)
+{
+    out->switch_ins = __atomic_load_n(&sc_stats.switch_ins, __ATOMIC_RELAXED);
+    out->bad_gen = __atomic_load_n(&sc_stats.bad_gen, __ATOMIC_RELAXED);
+    out->bad_dual = __atomic_load_n(&sc_stats.bad_dual, __ATOMIC_RELAXED);
+    out->first_kind = __atomic_load_n(&sc_stats.first_kind, __ATOMIC_ACQUIRE);
+    out->first_task_id = sc_stats.first_task_id;
+    out->first_cpu = sc_stats.first_cpu;
+    out->first_owner = sc_stats.first_owner;
+}

+/* ============================================================================
+ * R3 (#1234, #1238): READY tasks migrated between CPUs while the CPU they
+ * last ran on is still switching out of them.
+ *
+ * schedule() puts a running task back on its run queue as READY under
+ * rq_lock and drops the lock before switch_to() has saved the task's
+ * context. Workers (unpinned) loop on yield(); one mover per CPU (pinned)
+ * scans the workers, migrates a READY one to its own CPU with
+ * sched_migrate_task() and yields at once, so its CPU switches the worker
+ * in while the worker's previous CPU may still be inside its switch
+ * window. Checks, per worker:
+ *  - generation: before each yield the worker stamps its private counter
+ *    into swo_gen[i]; after the yield returns it compares the two. A
+ *    context restored from a save older than the last stamp resumes with
+ *    an old counter (restored before its save completed);
+ *  - two CPUs: the worker marks itself in swo_in[i] (cpu + 1) with an
+ *    atomic exchange while it runs test code and clears it before the
+ *    yield; a nonzero previous value means another CPU runs it too.
+ * With SWITCH_CHECK=ON the kernel also checks every switch-in (saved
+ * generation vs restored generation, and a per-slot owner), and those
+ * counters must not move during the test.
+ * ============================================================================ */
+
+#define SWO_WORKERS_PER_CPU 2
+#define SWO_MAX_CPUS        8
+#define SWO_MAX_WORKERS     (SWO_WORKERS_PER_CPU * SWO_MAX_CPUS)
+#define SWO_RUN_MS          300
+
+static volatile uint32_t swo_stop;
+static volatile uint32_t swo_bad_gen;
+static volatile uint32_t swo_bad_dual;
+static volatile uint32_t swo_first_kind;     /* 1 gen, 2 two CPUs */
+static volatile uint32_t swo_first_worker;
+static volatile uint32_t swo_first_cpu;
+static volatile uint64_t swo_first_have;
+static volatile uint64_t swo_first_want;
+static volatile uint64_t swo_gen[SWO_MAX_WORKERS];
+static volatile uint32_t swo_in[SWO_MAX_WORKERS];
+static volatile uint32_t swo_runs[SWO_MAX_WORKERS];
+static volatile uint32_t swo_migs;
+static volatile uint32_t swo_mig_fail;
+static struct task *volatile swo_task[SWO_MAX_WORKERS];
+static volatile uint32_t swo_nworkers;
+
+static void swo_note(uint32_t kind, uint32_t i, uint64_t have, uint64_t want)
+{
+    uint32_t zero = 0;
+    if (__atomic_compare_exchange_n(&swo_first_kind, &zero, kind, false,
+                                    __ATOMIC_RELAXED, __ATOMIC_RELAXED)) {
+        swo_first_worker = i;
+        swo_first_cpu = cpu_id();
+        swo_first_have = have;
+        swo_first_want = want;
+    }
+}
+
+static void swo_worker(void *arg)
+{
+    uint32_t i = (uint32_t)(uintptr_t)arg;
+    uint64_t local = 0;     /* lives across yield() in a callee-saved register */
+    while (!__atomic_load_n(&swo_stop, __ATOMIC_ACQUIRE)) {
+        uint32_t me = cpu_id() + 1;
+        uint32_t other = __atomic_exchange_n(&swo_in[i], me, __ATOMIC_ACQ_REL);
+        if (other != 0) {
+            __atomic_fetch_add(&swo_bad_dual, 1, __ATOMIC_RELAXED);
+            swo_note(2, i, other, me);
+        }
+        uint64_t stamped = __atomic_load_n(&swo_gen[i], __ATOMIC_ACQUIRE);
+        if (stamped != local) {
+            __atomic_fetch_add(&swo_bad_gen, 1, __ATOMIC_RELAXED);
+            swo_note(1, i, local, stamped);
+            local = stamped;   /* resynchronise so one event counts once */
+        }
+        local++;
+        __atomic_store_n(&swo_gen[i], local, __ATOMIC_RELEASE);
+        __atomic_fetch_add(&swo_runs[i], 1, __ATOMIC_RELAXED);
+        uint32_t mine = me;
+        (void)__atomic_compare_exchange_n(&swo_in[i], &mine, 0, false,
+                                          __ATOMIC_ACQ_REL, __ATOMIC_RELAXED);
+        yield();
+    }
+}
+
+static void swo_mover(void *arg)
+{
+    uint32_t me = (uint32_t)(uintptr_t)arg;
+    uint32_t start = me;
+    while (!__atomic_load_n(&swo_stop, __ATOMIC_ACQUIRE)) {
+        uint32_t n = swo_nworkers;
+        bool moved = false;
+        for (uint32_t k = 0; k < n && !moved; k++) {
+            uint32_t i = (start + k) % n;
+            struct task *t = swo_task[i];
+            if (__atomic_load_n(&t->state, __ATOMIC_ACQUIRE) != TASK_READY ||
+                t->assigned_cpu == me) {
+                continue;
+            }
+            if (sched_migrate_task(t, me) == 0) {
+                __atomic_fetch_add(&swo_migs, 1, __ATOMIC_RELAXED);
+                moved = true;
+            } else {
+                __atomic_fetch_add(&swo_mig_fail, 1, __ATOMIC_RELAXED);
+            }
+            start = i + 1;
+        }
+        /* Switch the migrated worker in on this CPU at once (it is ahead
+         * of this mover in the queue at equal priority). */
+        yield();
+    }
+}

+# ADR 0008: a task is switched in only after its previous CPU has saved it
+
+## Status
+
+Proposed (switch gauntlet run 5, C2). Design checkpoint before any fix code;
+the blind design critic reviews it against the code.
+
+## Context
+
+### The sequence being closed
+
+`on_cpu` (#1213, #1237) is set to 1 by the CPU that switches a task in, under
+that CPU's `rq_lock`, and cleared with a store-release by the same CPU in
+`sched_finish_switch()` right after `switch_to()` has written the task's
+callee-saved registers, SP, FP/SIMD state and DAIF into `task->context` and
+moved SP off the task's stack. Until then the task's saved context is stale
+(it holds the previous switch-out) and its stack is live.
+
+A task becomes runnable on another CPU while `on_cpu` is still set in two
+ways:
+
+1. **Requeue path.** `schedule()` on CPU A puts its RUNNING `current` back
+   on A's queue as READY, picks another task, and drops `rq_lock[A]`
+   (`rq_unlock_irqrestore`, which also restores the caller's IRQ mask)
+   before `switch_to()`. In that window any path that takes `rq_lock[A]`
+   can move the READY task to CPU B: `sched_migrate_task` (from
+   `sched_set_task_affinity`, the Lua binding `lua_slm.c`, tests),
+   `sched_try_steal` (WORK_STEALING), and `sched_rebalance_tick` (heuristic
+   policy, CPU 0's tick). B's `schedule()` then picks it and `switch_to()`
+   loads the stale context while A is still running on that stack.
+2. **Wake path.** A task sets `TASK_BLOCKED` and publishes itself on a wait
+   structure (`task_sleep_ms`: sleep queue; `pi_mutex_lock`: wait queue;
+   `ipc.c block_on_queue`) under that structure's lock, drops the lock, and
+   only then calls `schedule()`. A waker that takes the lock in between
+   (`task_sleep_wake`, `pi_mutex_unlock` hand-off, `ipc wake_one`,
+   `task_wake_sleepers` from any CPU's tick) sets READY and enqueues it on
+   a CPU chosen by `assigned_cpu`, affinity or the policy's `assign_cpu`.
+   That CPU can switch it in before the blocking CPU has even entered
+   `schedule()`, a window of the whole `schedule()` prelude plus the
+   switch.
+
+Neither path checks `on_cpu`. Evidence on the base (main 8ec0e330 +
+c1/harness 6e39f425 + the tests, `c2/switch-window` 88d4d71b):
+

+### Why the reverted design deadlocked (run 4)
+
+1ead6ef6 spun on `next->on_cpu` under `rq_lock[B]`. The outgoing CPU A's
+window is open to IRQs (`rq_unlock_irqrestore` restores the caller's DAIF;
+`switch_to` restores the incoming task's DAIF before `sched_finish_switch`).
+A tick on A inside the window runs `task_wake_sleepers` ->
+`scheduler_add_task_to_cpu(t, B)` -> `spin_lock(rq_lock[B])`, held by B
+waiting for A: a cycle (critic-4-C1.md section 1.5; 2 of 2 at 6d4fe041).
+x86 had a second cycle through the resched IPI (#1236).
+
+There is a third cycle the spin design has even with IRQs masked through
+the window (shape (c) below), through the wake path: task P runs on A and
+task Q runs on B; each blocks (TASK_BLOCKED published) and each is woken
+onto the other CPU before it calls `schedule()` (for example two pi_mutex
+hand-offs, or `ipc wake_one` placing by policy). A's `schedule()` does not
+requeue P (it is READY, not RUNNING), picks Q and spins on Q's `on_cpu`
+under `rq_lock[A]`; B picks P and spins on P's `on_cpu` under `rq_lock[B]`.
+Each `on_cpu` is cleared only by the CPU that is spinning on the other. No
+IRQ is involved. 1ead6ef6's argument ("next must already be on that queue,
+so two CPUs cannot each wait for the other's outgoing task") assumed the
+requeue path only.
+
+## Decision
+
+**Defer the switch-in, never wait for it under a lock.** In `schedule()`
+(and `scheduler_start()`), under `rq_lock[B]`, after `next` is chosen and
+before anything else is done with it:
+
+```c
+if (next != current && next != rq->idle_task &&
+    __atomic_load_n(&next->on_cpu, __ATOMIC_ACQUIRE)) {
+    /* Previous CPU has not finished switching out of next (#1234). Leave
+     * it at the head of this queue and run idle, which polls without
+     * sleeping until a schedule() finds it released. */
+    switch_in_deferred[B] = 1;
+    next = rq->idle_task;
+} else {
+    switch_in_deferred[B] = 0;
+}
+```
+
+- `next` stays queued (it is not removed: the removal below only removes
+  `rq->head` when it is `next`). A requeued `current` stays queued too; the
+  CPU switches to its idle task, or keeps running idle if `current` is
+  idle (then `next == current` and nothing switches).
+- The idle loop checks `switch_in_deferred[cpu_id()]` before WFI/WFE/HLT; if
+  set it skips the wait and calls `yield()` at once, so the deferred task
+  is picked within one `schedule()` of its release. The flag is per-CPU,
+  written and read only by its CPU.
+- Nothing else changes: migrate, steal, rebalance, wake placement and
+  `task_destroy` keep their code. Every path that can make a task runnable
+  on another CPU (including ones added later, and the Lua binding) is
+  closed at the single point where a context is restored.
+
+### Candidate shapes considered
+
+- (a) Migrate, steal and rebalance refuse a task with `on_cpu` set, and wake
+  placement redirects it to the CPU it is on. Correct only if every enqueue
+  path is covered (seven today: migrate, steal, rebalance,
+  `scheduler_add_task`, `scheduler_add_task_to_cpu`, `sched_set_task_affinity`,
+  and the requeue itself); the wake path needs the running CPU recorded
+  separately from `assigned_cpu` (which `sched_migrate_task` rewrites for a
+  BLOCKED task, as `test_preempt_flag_follows_migrated_task` does); a
+  refused `sched_set_task_affinity` leaves a task off its affinity. Rejected:
+  many sites, and one missed site reopens the window.
+- (b) The waiter spins with no run-queue lock held and re-validates. Fine for
+  `sched_migrate_task` from task context, but the pick in `schedule()`
+  cannot spin anywhere in the outgoing-CPU sequence without the cross-CPU
+  cycle above (both CPUs in their own windows, each waiting for the other's
+  task). Spinning before taking `rq_lock[B]` has nothing to wait on yet.
+  The decision is (b) reduced to its safe form: the waiting happens in the
+  idle loop, which holds nothing.
+- (c) Keep the outgoing CPU's IRQs masked from the context save through the
+  `on_cpu` release, then spin under `rq_lock`. Removes the tick and IPI
+  cycles but not the wake-path cycle, and needs `context.S` (ARM64 DAIF,
+  and FIQ for `PI5_FIQ_TIMER`), x86 RFLAGS and `task_entry_wrapper`
+  changes. Rejected.
+
+## Lock graph
+
+Locks (all spinlocks; `_irqsave` unless noted): `rq_lock[c]`,
+`steal_deque_lock[c]`, `sleep_queue_lock`, `pi_mutex.guard`, ipc queue
+locks, `task_lock` (task table), `sched_model_lock` /
+`sched_model_stage_lock` (AI runtime config), the UART lock.
+
+Edges (A -> B means B is taken while A is held), from the code at 88d4d71b:
+
+| Path | Locks, in order |
+|---|---|
+| `schedule()` on B (switch-out side) | `steal_deque_lock[v]` (released), then `rq_lock[v]` (released) in `sched_try_steal`; then `rq_lock[B]`; zombie reap drops it around `task_destroy_gen` (task_lock, PMM; its `on_cpu` wait holds no run-queue lock); `rq_lock[B]` dropped before the window. Window, `switch_to`, `sched_finish_switch`: no lock. |
+| new: deferral | one load-acquire under `rq_lock[B]`; no wait. Idle poll: no lock, IRQs unmasked. |
+| tick (`scheduler_tick`, any CPU, also inside that CPU's own window) | `sleep_queue_lock` (released) then per woken task `rq_lock[t]` (released) then `steal_deque_lock[t]`; AI: `rq_lock[c]` one at a time in `ai_update_top_tasks`; heuristic: `rq_lock[busy]` (released), `rq_lock[idle]` (released), `steal_deque_lock[idle]`. Never nested. |
+| `sched_migrate_task` | `rq_lock[min]` -> `rq_lock[max]` (ascending CPU id). |
+| `sched_try_steal` | `steal_deque_lock[v]` released before `rq_lock[v]`. |
+| `scheduler_add_task_to_cpu` | `rq_lock[c]` released before `steal_deque_lock[c]`. |
+| `pi_mutex_lock` / unlock | `guard` -> `rq_lock[c]` (reposition); unlock drops `guard` before `scheduler_add_task_to_cpu`. |
+| `ipc wake_one` | ipc queue lock -> `rq_lock[c]` (via `scheduler_add_task`). |
+| `task_destroy` | `on_cpu` wait (load-acquire, 2 s bound) with no lock held, then `task_lock` alone; PMM after. (`ai_update_top_tasks`' comment says the generation bump holds the rq_lock too; the code takes only `task_lock`.) |
+| x86 resched IPI | handler returns while `preempt_disabled[cpu]` (#1236); otherwise `schedule()` as above. |
+
+The only nesting among run-queue locks is migrate's ascending pair; the
+other nestings are outer non-scheduler locks over a single `rq_lock`, never
+the reverse (nothing under `rq_lock` takes `guard`, an ipc lock or
+`sleep_queue_lock`). The graph is acyclic and the decision adds no edge.
+
+### Why no deadlock with a tick or IPI anywhere in the window
+
+The decision adds exactly one wait-for relation: CPU B's idle task polls
+until CPU A clears `next->on_cpu`. While polling B holds no lock and has
+IRQs unmasked. A clears `on_cpu` after finishing its window, `switch_to`
+and the call to `sched_finish_switch`; on that path A takes no lock except
+inside interrupt handlers, and a handler's locks (`rq_lock[*]`,
+`sleep_queue_lock`, `steal_deque_lock[*]`) are each held by their holders
+only for bounded sections that do not wait on any CPU's `on_cpu`. B in
+particular holds `rq_lock[B]` only inside `schedule()`, where the deferral
+is a single load. So A's progress depends on no action of B, and no cycle
+can close through B. A tick on B while it polls is ordinary (preemption of
+idle). A tick on A in its window runs `scheduler_tick`, which returns
+without scheduling while `preempt_disabled[A]` is set, as today. The x86
+resched IPI is unchanged (#1236). The cross-CPU wake cycle cannot form
+because neither CPU waits: each defers the other's task and runs idle.
+
+Forced check: R1 phase B puts a tick into CPU 0's held window that takes
+CPU 3's `rq_lock` while CPU 3 has picked the migrated task (no-deadlock
+bar). The fix head must complete it; `c2/reverted-wait` (1ead6ef6's spin
+on this base) must hang there.
+
+## Ordering argument (Arm ARM DDI 0487, B2.3)
+
+- **Publishing store:** the `stlr` of `prev->on_cpu = 0` in
+  `sched_finish_switch()` on A. Every memory access before it in program
+  order, which includes `switch_to`'s `stp`/`str` of x19 to x30, SP,
+  q0 to q31, FPCR, FPSR and DAIF into `prev->context`, and A's last use of
+  `prev`'s stack, is Barrier-ordered-before it (Store-Release).
+- **Acquiring load:** the `ldapr` of `next->on_cpu` in B's `schedule()`
+  under `rq_lock[B]`. It is Barrier-ordered-before every later access in
+  program order on B, including `switch_to`'s loads of `next->context`
+  after `rq_unlock` (Load-AcquirePC; program order survives the unlock).
+- If B's load reads 0 from A's store (reads-from, external), the save is
+  Ordered-before the restore loads, so they see the saved values.
+- **Which 0 it can read.** The 1 written at the task's last switch-in (a
+  plain store under `rq_lock[A]`) is ordered before B's load by the lock
+  chain that delivered the task to B's queue: requeue path, A's `rq_unlock`
+  (release) -> mover's `rq_lock[A]` (acquire) -> mover's `rq_unlock[B]` ->
+  B's `rq_lock[B]`; wake path, the task's own program order on A after the
+  1, then the wait-structure lock release -> waker's acquire -> waker's
+  `rq_lock[B]` release -> B's acquire. So B cannot read an older 0 than
+  that 1 (coherence), only the 1 or A's release of it.
+- Once B has removed `next` from its queue and set `on_cpu = 1` under
+  `rq_lock[B]`, no other CPU can pick it (it is on no queue), so nothing
+  can re-open the window between B's check and B's `switch_to`.
+- x86-64: TSO; the same `__atomic` release/acquire compile to plain moves
+  with compiler barriers, which TSO orders.
+
+## Invariant established
+
+A CPU restores a task's context only after the CPU that last saved it has
+published the save (`on_cpu` store-release), observed by the restoring CPU
+with a load-acquire under its own `rq_lock`. No CPU waits for that while
+holding a lock.
+
+## Consequences
+
+- One load and a compare per context switch. bench smp context-switch time
+  is measured against the base (bar: within 10%).
+- A deferred task waits for its previous CPU's window (normally tens of
+  instructions; longer if that CPU takes an interrupt in it) while the
+  deferring CPU runs idle: the deferring CPU loses at most one `schedule()`
+  of a lower-priority `current`.
+- Stealing or migrating a task mid-switch is still allowed and simply
+  waits; rebalance and steal could skip such tasks as an optimisation
+  (not done).
+- R3 makes `sched_migrate_task` print "Cannot migrate running task" about
+  14 times per iteration on Jetson (2741 lines in 200 iterations) and about
+  800 times per 300 ms in QEMU: a benign race between the caller's state
+  read and migrate's unlocked RUNNING check. Not a rate distortion; no
+  rate limit in this decision.
+- Side defect seen in the trace, not part of this decision: #1241
+  (`sched_migrate_task` rewrites `assigned_cpu` of a task queued on another
+  CPU).
+
+## What would overturn this
+
