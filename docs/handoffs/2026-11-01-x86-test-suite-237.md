### 1.1 Fixes in `c046eb87`

- **#GP (SysV stack alignment).**
  - New tasks (`kernel/sched/task.c`), ELF tasks (`kernel/src/elf.c`) and
    AP entry (`kernel/arch/x86_64/ap_trampoline.S`) entered their first C
    frame with RSP 8 bytes off the SysV requirement, so `movaps` spills
    faulted.
  - Task and ELF stacks now reserve the return-address slot, and the AP
    trampoline uses `call` instead of `jmp`.
- **Model memory.**
  - 256 MB weights + 128 MB workspace cannot fit a 256 MB guest, and the
    suite also needs a 48 MB FAT32 ramdisk (an order-14 buddy block).
  - The x86 `QEMU_MEMORY` is now `1G` (Makefile), matching ARM64.
  - The pools in `config.h` were deliberately left unchanged, so the real
    x86 test PC keeps full-size pools.
- **Lua.**
  - A weak `lua_shell_init` stub in `platform_x86.c` satisfied the
    reference, so the real archive member never linked. The stub is
    removed.
  - `kernel/tests/test_harness.c` registers Lua directly, because the
    IDLE-priority shell task never runs during the suite.
- **Timer/resched vectors 48/49 moved from IST1 to IST=0.**
  - These handlers can `schedule()` from the ISR. On IST1 a preempted
    task's saved RSP pointed into the shared per-CPU IST stack, and the
    next tick overwrote it.
  - This **reverses the A1/P1-1 hardening** for these two vectors. The
    per-CPU TSS and IST1 stack stay installed.
  - Flagged for reviewer attention in the PR.
- **kprintf `%f/%g/%e`.**
  - On x86-64 a `va_list` parameter decays to a pointer, so `&param` was
    wrong.
  - `fmt_vprintf` (`kernel/src/kprintf.c`) now `va_copy`s into a local.
    This is shared code and is ARM64-neutral.
- **isa-debug-exit.**
  - `semihosting_exit` double-encoded the value, so a passing run exited
    with code 3. Fixed in `kernel/src/semihosting.c`.
- **Tests.**
  - The shell test mocks now zero-initialize optional callbacks.
  - Six stale `test_x86_boot` tests were updated for LAPIC/IOAPIC/q35.
  - New regression tests cover task/AP stack alignment, IST=0 on vectors
    48/49, and preemption of a CPU-bound task.
- **Docs.**
  - Updated: `docs/smp.md`, `docs/scheduler.md`, `docs/architecture.md`,
    `docs/fact-sheets/preemption.md`, `docs/model-memory.md`,
    `docs/benchmarks.md`, `kernel/CLAUDE.md`, `CLAUDE.md`.
